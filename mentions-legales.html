4. Politique de remboursement et de remplacement

Les codes digitaux sont des produits numériques livrés immédiatement. Par principe, une fois le code transmis, il n'est ni repris, ni échangé, ni remboursé. Nous garantissons toutefois une solution dans les cas suivants :

SituationSolution
Paiement reçu mais code non livré sous 24 hLivraison immédiate ou remboursement intégral
Produit en rupture de stock après paiementProduit équivalent ou remboursement intégral
Code invalide ou déjà utilisé au moment de la livraison (preuve à l'appui)Remplacement du code après vérification auprès du fournisseur
Erreur de notre part (mauvais produit, mauvaise région, mauvais montant par rapport à la commande confirmée)Remplacement ou remboursement
Erreur de région ou de plateforme choisie par le clientAucun remboursement
Code révélé, partagé ou utilisé par un tiers après livraisonAucun remboursement
Compte suspendu par l'éditeur (Sony, Microsoft, Epic, etc.)Aucun remboursement

Comment faire une réclamation

  1. Contactez-nous sur WhatsApp au +224 662 24 30 70 dans les 48 heures suivant la livraison.
  2. Indiquez la référence de votre transaction Mobile Money et le code concerné.
  3. Joignez une capture d'écran du message d'erreur affiché lors de l'activation.

Nous traitons chaque réclamation sous 72 heures ouvrées. Les remboursements validés sont effectués via le moyen de paiement utilisé lors de l'achat (Orange Money ou MTN Mobile Money), sous 7 jours.

5. Signalement d'abus
